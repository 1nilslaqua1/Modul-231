# Szenario: Verlust des persönliches Smartphones.

Welche Funktionen / Services können beim Verlust des persönlichen Smartphones nicht mehr verwendet werden (Einzelne Funktionen, Apps auflisten)? 
- Temporär natürlich alle Funktionen die ein Smartphone zur Verfügung stellt.
Andererseits, auch wenn man ein neues Smartphone hat, können nicht gespeicherte Daten verloren gehen.

Welche Daten sind beim Verlust betroffen?
- Daten, die nicht gebackupt worden sind. Das können Fotos, Videos oder Dateien sein.

Wo liegt das Backup der Daten?
- Ein Backup liegt meist direkt im Cloud-Speicher.

Wie können die Daten wiederhergestellt werden?
- Bei der Anmeldung in das entsprechende Konto, worauf die Cloud war, z.B. Apple Account, 
kann man auf die Cloud zugreifen und dadurch den aktuellsten Stand der Daten abrufen und die Daten wieder Herunterladen.
