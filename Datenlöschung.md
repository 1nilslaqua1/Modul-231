# Datenlöschung #

-Was ist die Problematik bei der Datenlöschung aus Backups?
 
 - personenbezogene Daten löschen
 - Daten werden nicht mehr benötigt, sind aber vertraulich
 - Backups sind dafür ausgelegt, Daten wieder herzustellen, macht es einfacher gelöschte Daten zu hacken

-Was ist die Problematik bei der Datenlöschung aus Archiven (unveränderbaren Backups - Beispielsweise gebrannte DVD's)?
 
 - Archive beinhalten historische und geschäftliche Informationen
 - Daten im Archiv können nicht verändert werden
 - Daten im Archiv müssen grundsätzlich aufbewahrt werden
 - Daten (bsp. DVD) müssten physisch vernichtet werden

-In welchen Fällen können Sie Ihr Recht auf Löschen durchsetzen und wann greifen übergeordnete Interessen bzw. rechtliche Forderungen, die Ihr Recht auf Löschen ausser Kraft setzen?

Daten dürfen mit ihrem Recht gelöscht werden, wenn:
 -Die Daten nicht mehr für den <ursprünglichen Zweck verwendet werden
 - Daten unrechtmässig verarbeitet werden
Datenlöschung wird verhindert durch:
 - Gesetzliche, vrtragliche oder rechtliche Pflicht

## Backup = kurzfristige Speicherung, ideal zur Wiederherstellung
## Archiv = langfristiges Speichern, sollte unveränderbar sein
