## Fachbegriffe zum Thema Backup

Ein Backup ist eine Sicherheitskopie von Daten, die erstellt wird, um Datenverlust zu vermeiden. 
Gründe für Datenverluste können Hardwaredefekte, Softwarefehler, Schadsoftware oder Bedienungsfehler sein. 
Durch regelmässige Backups können wichtige Daten im Notfall wiederhergestellt werden.

Zu den wichtigsten Begriffen gehören:
Vollbackup, bei dem sämtliche Daten gesichert werden, sowie das inkrementelle und differenzielle Backup.
Beim inkrementellen Backup werden nur die Änderungen seit der letzten Sicherung gespeichert, während beim differenziellen Backup alle Änderungen seit dem letzten Vollbackup berücksichtigt werden. 
Ebenfalls wichtig ist der Begriff Restore, der die Wiederherstellung gesicherter Daten beschreibt.
Eine bewährte Methode zur Datensicherung ist die **3-2-1-Regel**: Es existieren drei Kopien der Daten, die auf mindestens zwei unterschiedlichen Speichermedien gespeichert werden, wobei sich eine Kopie an einem externen Standort befindet.
