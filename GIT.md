# Verständnisfragen Git

## 1. Was bedeutet die Abkürzung DVCS?
DVCS steht für **Distributed Version Control System**.

## 2. Wie heisst das bekannteste DVCS System?
Das bekannteste DVCS System ist **Git**.

## 3. Was ist der Unterschied zwischen einer zentralisierten und einer dezentralisierten Versionsverwaltung?
- **Zentralisiert:** Es gibt einen zentralen Server, auf dem alle Versionen gespeichert werden
- **Dezentralisiert:** Jeder Benutzer besitzt eine vollständige Kopie des Repositories inklusive Historie

## 4. Was bedeutet in diesem Zusammenhang die Abkürzung "MD"?
MD steht für **Markdown**.

## 5. Weshalb ist "MD" im Zusammenspiel mit DVCS so nützlich?
Markdown-Dateien sind reine Textdateien. Änderungen können dadurch von Git einfach erkannt und verglichen werden.

## 6. Was ist wesentlich umfangreicher als "MD" und wird häufig für wissenschaftliche Arbeiten verwendet?
**LaTeX** ist wesentlich umfangreicher als Markdown und wird oft für wissenschaftliche Arbeiten wie Bachelorarbeiten verwendet.

## 7. Weshalb ist der Einsatz von docx-Dateien mit dem bekanntesten DVCS System problematisch?
DOCX-Dateien sind Binärdateien. Änderungen können nicht einfach verglichen werden, wodurch sowohl die Versionskontrolle als auch die Zusammenführung erschwert werden.
