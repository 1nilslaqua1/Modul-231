-DHCP Server vergibt IP Adressen 

-LAN Local area network (begrenztes Netzwerk)

-Router verbindet 2 verschiedene Netzwerke 

-KMU (kleinere und Mittlere Unternehmen) vernetzt

-DNS (Domain name system) übersetzt Domainnamen (einmalig) in IP adressen, ermöglicht die Kommunikation



-Messbare Netzwerk-Anforderungen: 
 - X clients unterstützen
 - (Fileserver) X Mbit/s sicherstellen
 - Netzwerk“drucker“ soll von allen Arbeitsplätzen erreichbar sein
