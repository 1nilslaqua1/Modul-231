Windows bietet verschiedene Möglichkeiten zur Sicherung persönlicher Daten und Systemeinstellungen. 
Backups helfen dabei, verloren gegangene Daten nach einem Defekt oder einem Fehler wiederherzustellen. 
Dabei können z.B. Cloud-Dienste verwendet werden.

Beim Offline-Backup werden die Daten meist externen Festplatte oder einem USB-Stick gespeichert. 
Der Vorteil besteht darin, dass keine Internetverbindung benötigt wird und die Daten vollständig unter eigener Kontrolle bleiben. 
Beim Online-Backup werden die Daten hingegen in einer Cloud gespeichert. Dadurch können die Sicherungen von verschiedenen Geräten aus erreicht werden und sind auch bei Diebstahl oder Beschädigung des eigenen Computers verfügbar.
Viele Unternehmen und Privatpersonen kombinieren beide Varianten, um die Sicherheit ihrer Daten zu erhöhen.
