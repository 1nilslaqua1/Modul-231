Verschlüsselung dient dafür, dass unbefugte Leute keinen zugriff auf Daten haben.
Dabei werden Daten so verändert, dass sie nur von berechtigten Personen gelesen werden können.
Moderne Kommunikationssysteme verwenden Verschlüsselung, um Daten während der Speicherung oder Übertragung zu schützen.

Bei der symmetrischen Verschlüsselung wird derselbe Schlüssel sowohl zum Verschlüsseln als auch zum Entschlüsseln verwendet. 
Dieses Verfahren arbeitet sehr schnell und wird deshalb häufig für grosse Datenmengen eingesetzt. 
Der Nachteil besteht darin, dass beide Kommunikationspartner denselben Schlüssel besitzen müssen.

Die asymmetrische Verschlüsselung verwendet ein Schlüsselpaar aus öffentlichem und privatem Schlüssel.
Das öffentliche Schlüssel darf frei verteilt werden, während der private Schlüssel geheim bleibt.
Daten, die mit dem öffentlichen Schlüssel verschlüsselt werden, können nur mit dem zugehörigen privaten Schlüssel entschlüsselt werden.
Dieses Verfahren ist zwar langsamer, ermöglicht jedoch einen sicheren Schlüsselaustausch.
